mistlib

開発中

  • P2P
  • RUST

Unityに依存しない、Web・ネイティブ両対応のP2P通信ライブラリ

GitHub 開発履歴 MistNet（旧版） ICCE-Taiwan 2024
詳細

仮想空間で近くの相手と情報を共有するP2P通信ライブラリです。Unity専用だったMistNetを置き換え、WebアプリからもDLLとしても使えるようにしました。

AIコーディングツールと一緒に、Rustコアとネイティブ版、WebAssembly版の実装・テストを進めています。

位置とAOI（周囲の関心領域）から、近傍と各方向の接続相手を選びます。直接つながっていない相手へのメッセージは、参加者の接続網で中継します。

Rust製で、通信にはWebRTC DataChannelを使います。ネイティブライブラリとブラウザ用WebAssembly、npm @tik-choco/mistlibをMPL-2.0で公開しています。

NostrリレーとSTUNを使い、必要に応じてTURNも使います。既定の接続予算は各ノード30で、全体の参加人数の上限や性能保証ではありません。

MistNet（旧版）

mistlibの前身です。Unityの仮想空間で通信とオブジェクトの同期（位置・アニメーション・変数・RPC）を扱うWebRTCライブラリで、MITライセンスです。ICCE-Taiwan 2024の論文はこのMistNetについてのものです。

mistlib-examples

Python・Web・Unity向けクライアントと使用例で、ライセンスはApache-2.0です。エンジンは別途必要で、READMEにWeb/WASM、Python・Unity/nativeの構成を載せています。

mistlib-unity

mistlibをUnityから使うための実験的なバインディングです。対応環境と制限はREADMEを参照してください。バインディング等はApache-2.0、ネイティブエンジンはMPL-2.0です。

mistlib-consensus

P2Pメッシュ向けの複製状態機械で、信頼できるピア間ではRaft、信頼できないピアを含む場合はHotStuffを使います。Rust製でコアはネイティブとwasm32に対応し、MPL-2.0の実験的な実装で、セキュリティ監査は未実施です。

mistai

HTTPモデル接続の共有とP2P AIルーム用のTypeScriptライブラリで、チャット・TTS・STT・OpenAI互換HTTPトンネルが、注入した1つのトランスポートを共有します。Preact製の設定UIは任意で使え、ライセンスはMPL-2.0です。

プレイ 公式紹介 配布ページ（旧Unity版）
詳細

森で建築やクラフト、魔法づくりができるブロックサンドボックスです。もともとUnityで作っていましたが、Webゲームとして作り直しています。

Unity版・Web版とも、ゲームの設計とプログラムのほぼすべてを担当しています。

舞台はシードから生成する1 km × 1 kmの密な森で、ブロック・線・壁・床・設計図による建築、クラフト、魔法装置、夜のモンスター、「blight」エリアを実装しています。魔法は元素・形状・振る舞い・条件を組み合わせるノードグラフで、LLMでも生成できます。

Web版はPreact・Vite・TypeScript・three.js製で、UIは英語・日本語・中国語に対応し、ランチャーなしでブラウザから遊べます。公式サイトで紹介しています。BOOTHで配布しているランチャー版は、以前のUnity版です。

Web版を作り直している途中です。mistlibによるP2P協力プレイ、リンクやコードでのルーム参加、パーティーのボイスチャット・画面共有、VRMアバターに対応しています。専用ゲームサーバーは不要です。Unity版の開発はやめています。

MISTL

開発中

  • P2P
  • CLI

tik-chocoの機能をまとめたCLI

GitHub リリース
詳細

tik-chocoの各種機能を1つのバイナリにまとめた、mistlib上で動くRust製デーモンCLIです。

設計を考え、AIコーディングツールと一緒にRustで実装しています。

tc-storage互換のdid:key（Ed25519）IDとコンテンツアドレス方式のストレージ、VRChatのAVProプレイヤーで再生できる画面共有RTSPサーバー、ブラウザのタブを開かずにチャットを続けるtc-chatリレーを備えています。mistネットワーク経由のP2Pポート転送は接続ごとの承認・トラストストア・監査ログに対応し、mistai互換のP2P AIネットワークも使えます。

Windows版は単体で動くmistl.exeとして配布し、コマンドはmistl、内蔵Webダッシュボードは英語・日本語対応でhttp://127.0.0.1:6480/から使えます。ソースコードとリリースはGitHub、ライセンスはMPL-2.0です。

開発中です。新しい版はGitHubのリリースページで公開しています。
