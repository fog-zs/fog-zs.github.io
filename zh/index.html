mistlib

开发中 / API尚未稳定

让虚拟空间中的参与者与附近节点共享信息的P2P通信库。

  • Rust
  • WebRTC
  • WebAssembly
  • MPL-2.0
GitHub 开发记录
详情

成果物

Rust / WebRTC DataChannel。原生库与浏览器WebAssembly，npm @tik-choco/mistlib。MPL-2.0。

设计与技术

README说明：根据位置和AOI（周围的关注区域）选择附近及各方向的连接对象。发送给其他节点的消息经由参与者构成的连接网络转发。

当前状态

使用Nostr中继、STUN及必要时的TURN。默认连接数30是每个节点的连接预算，不是总参与人数或性能保证。

mistlib-examples

Python、Web、Unity客户端及使用示例。需要另行取得引擎。Apache-2.0。README说明了Web/WASM以及Python或Unity/native的配置。

mistlib-unity

实验性Unity绑定。要求Unity 6000.0以上，面向Windows/Linux x86_64和Apple silicon macOS。不支持Android、iOS、WebGL。绑定等采用Apache-2.0，原生引擎采用MPL-2.0。重复运行Editor会话也有限制。

想在异世界生活

我的梦想是在异世界生活。

为此，我研究让参与者承担通信和状态共享的机制，并开发通信库与虚拟世界。

一个可以相遇、创造、积累生活的地方。通信延迟、状态一致性、防止作弊以及维持世界的机制，仍是需要继续面对的课题。
