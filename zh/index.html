mistlib

开发中

  • P2P
  • RUST

不依赖Unity、可用于Web和原生应用的P2P通信库

GitHub 开发记录 MistNet（旧版） ICCE-Taiwan 2024
详情

让虚拟空间中的参与者与附近节点共享信息的P2P通信库。它取代了只能在Unity中使用的MistNet，既可以在Web应用中使用，也可以作为DLL使用。

我与AI编程工具协作，推进Rust核心、原生库和WebAssembly版的实现与测试。

根据位置和AOI（周围的关注区域）选择附近及各方向的连接对象。没有直连的节点之间通过参与者组成的网络转发消息。

用Rust编写，通过WebRTC DataChannel通信。原生库、浏览器WebAssembly版和npm包@tik-choco/mistlib均以MPL-2.0许可发布。

使用Nostr中继和STUN，必要时使用TURN。每个节点的默认连接预算是30，这不代表总参与人数上限，也不保证性能。

MistNet（旧版）

mistlib的前身。用于在Unity虚拟空间中处理通信和对象同步（位置、动画、变量、RPC）的WebRTC库，采用MIT许可。ICCE-Taiwan 2024的论文讨论的就是MistNet。

mistlib-examples

Python、Web、Unity客户端和使用示例，采用Apache-2.0许可。需要另行取得引擎，README中有Web/WASM以及Python或Unity/native的配置说明。

mistlib-unity

用于在Unity中使用mistlib的实验性绑定。支持的环境和限制请参阅README。绑定等采用Apache-2.0，原生引擎采用MPL-2.0。

mistlib-consensus

用于P2P网状网络的复制状态机，可信节点之间用Raft，包含不可信节点时用HotStuff。用Rust编写，核心支持原生平台和wasm32，采用MPL-2.0许可，目前是实验性实现，尚未经过安全审计。

mistai

用于共享HTTP模型连接和P2P AI房间的TypeScript库，聊天、TTS、STT和OpenAI兼容HTTP隧道共用一个注入的传输层。Preact设置界面可以选用，采用MPL-2.0许可。

详情

在森林里建造、合成物品和设计魔法的方块沙盒。最初用Unity开发，现在正作为网页游戏重新制作。

无论Unity版还是网页版，游戏的设计和几乎全部程序都由我负责。

用种子生成1 km × 1 km的茂密森林，支持用方块、线、墙、地板和蓝图建造，也有合成、魔法装置、夜间怪物和“blight”区域。魔法用节点图组合元素、形状、行为和条件，也可以用LLM生成。

网页版用Preact、Vite、TypeScript和three.js开发，界面支持英语、日语和中文，无需启动器就能在浏览器中游玩。官网介绍游戏。BOOTH上的启动器版是以前的Unity版。

网页版正在重新制作中，支持基于mistlib的P2P合作游玩、通过链接或代码加入房间、队伍语音聊天和屏幕共享，以及VRM形象，无需专用游戏服务器。Unity版已停止开发。

MISTL

开发中

  • P2P
  • CLI

整合tik-choco功能的CLI

GitHub 发布版本
详情

运行在mistlib上的Rust守护进程CLI，把tik-choco的多种功能放在一个二进制文件里。

我负责设计，并与AI编程工具协作用Rust实现。

提供兼容tc-storage的did:key（Ed25519）身份和内容寻址存储、可用VRChat的AVPro播放器播放的屏幕共享RTSP服务器，以及不用打开浏览器标签页就能持续聊天的tc-chat中继。mist网络上的P2P端口转发支持逐连接审批、信任存储和审计日志，也支持兼容mistai的P2P AI网络。

命令是mistl，Windows版以可独立运行的mistl.exe发布，内置的Web控制面板位于http://127.0.0.1:6480/，支持英语和日语。源码和发布版本在GitHub上公开，采用MPL-2.0许可。

开发中。新版本发布在GitHub的发布页面上。
