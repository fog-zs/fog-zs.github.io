mistlib

In development

  • P2P
  • RUST

A P2P networking library for the web and native apps, without Unity

GitHub Development history MistNet (previous version) ICCE-Taiwan 2024
Details

A P2P networking library for sharing information with nearby peers in virtual spaces. It replaces MistNet, which only worked in Unity, and can be used from web apps or as a DLL.

I build and test the Rust core, native library and WebAssembly build together with AI coding tools.

It selects nearby peers and peers in each direction by position and area of interest (AOI). Messages to peers without a direct connection are relayed through the participant network.

Written in Rust, using WebRTC DataChannel for communication. The native library, browser WebAssembly build and npm package @tik-choco/mistlib are available under MPL-2.0.

It uses Nostr relays and STUN, with TURN when needed. The default connection budget is 30 per node; this does not set a total participant limit or guarantee performance.

MistNet (previous version)

The predecessor of mistlib. A WebRTC library for networking and object sync (position, animation, variables, RPC) in Unity virtual spaces, under the MIT license. The ICCE-Taiwan 2024 paper is about MistNet.

mistlib-examples

Python, Web and Unity clients and examples, licensed under Apache-2.0. A separate engine build is required; the README covers Web/WASM and Python or Unity/native setups.

mistlib-unity

Experimental bindings for using mistlib from Unity. See the README for supported platforms and limitations. Bindings and samples use Apache-2.0 and the native engine uses MPL-2.0.

mistlib-consensus

Replicated state machines for P2P meshes, using Raft for trusted peers and HotStuff when the network includes untrusted peers. Written in Rust with native and wasm32 core support under MPL-2.0; the implementation is experimental and has not had a security audit.

mistai

A TypeScript library for sharing HTTP model connections and running P2P AI rooms, with chat, TTS, STT and an OpenAI-compatible HTTP tunnel sharing one injected transport. A Preact settings UI is optional; the license is MPL-2.0.

Details

A block sandbox where you can build, craft and create spells in a forest. I first built it in Unity and am now remaking it as a web game.

I design the game and write almost all of its code, in both the Unity and web versions.

The world is a dense, seed-generated 1 km × 1 km forest with building using blocks, lines, walls, floors and blueprints, plus crafting, magic devices, night monsters and blight areas. Spells are node graphs combining element, shape, behavior and condition; an LLM can generate them too.

The web version uses Preact, Vite, TypeScript and three.js, has English, Japanese and Chinese UI, and runs in the browser without a launcher. The official site introduces the game. The launcher version on BOOTH is the earlier Unity version.

The web remake is in progress. It has mistlib P2P co-op, rooms joined by link or code, party voice chat and screen sharing, and VRM avatars, and needs no dedicated game server. I've stopped developing the Unity version.

MISTL

In development

  • P2P
  • CLI

A CLI for tik-choco features

GitHub Releases
Details

A Rust daemon CLI that runs on mistlib and packages tik-choco features in one binary.

I design it and implement it in Rust together with AI coding tools.

It provides tc-storage-compatible did:key (Ed25519) identity and content-addressed storage, a screen-sharing RTSP server playable by VRChat's AVPro player, and a tc-chat relay that keeps chat running without an open browser tab. P2P port forwarding over the mist network supports per-connection approval, a trust store and an audit log; a mistai-compatible P2P AI network is also supported.

The mistl CLI has a built-in English/Japanese web dashboard at http://127.0.0.1:6480/ and is distributed on Windows as a standalone mistl.exe. Source and releases are on GitHub under MPL-2.0.

In development. New versions are published on the GitHub releases page.
